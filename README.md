# steward-identity 🐹

> 🧭 Users, groups, roles, sign-in factors and SSO connections for Steward

## 📦 Install

```bash
go get github.com/Steward-GRC/steward-identity
```

## 🛠 Develop

```bash
task build    # go build ./...
task test     # go test ./...
task lint     # gofmt check + golangci-lint + yamllint
task license  # check Apache-2.0 headers (golic)
```
